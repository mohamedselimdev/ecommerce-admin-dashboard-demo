# E-Commerce Admin Dashboard (Demo)

An interactive Arabic (RTL) admin dashboard concept for an online phone and accessories store.

It shows the numbers an owner checks every day and the sections staff work in:

- Sales overview: KPIs, monthly target, sales chart with time ranges, top selling products
- Orders, products, banners, customers, returns and discounts sections
- Light and dark themes, collapsible sidebar, responsive layout

All data is sample data. The project is a single static page with no backend and is not connected to any live store.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy

The folder can be deployed as static assets, for example with Cloudflare Workers assets.
